# Ordini Clienti (Angular 17 LTS + PrimeNG)

App per gestione ordini con **lista piatti**, **carrello raggruppato**, **doppia valuta** EUR/WASHO (1 W = 1,5 €), **conferma ordine** e **stampa riepilogo**.

## Avvio

```bash
npm install
npm start
```

Apri: http://localhost:4200

## Note
- UI realizzata con componenti **PrimeNG** + utility CSS **PrimeFlex**.
- Layout ottimizzato per schermi **>= 10"**.
